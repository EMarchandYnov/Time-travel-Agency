# ⏳ TimeTravel Agency

Projet réalisé dans le cadre du module **Webapp Interactive** à Ynov Toulouse.

## 📖 Description

TimeTravel Agency est une application web interactive permettant aux utilisateurs de créer un voyage temporel personnalisé grâce à l'intelligence artificielle.

L'utilisateur pourra explorer différentes époques, définir ses préférences de voyage et obtenir un itinéraire unique généré en fonction de son profil.

## 🎯 Objectifs du projet

- Concevoir une expérience utilisateur immersive.
- Développer une application web interactive.
- Intégrer des fonctionnalités basées sur l'intelligence artificielle.
- Utiliser GitHub comme outil de gestion et de suivi du projet.
- Déployer une version fonctionnelle de l'application.

## 🚀 Fonctionnalités prévues

- Sélection d'une période historique.
- Création d'un profil voyageur.
- Agent conversationnel IA.
- Génération d'un voyage personnalisé.
- Création d'un passeport temporel.
- Interface responsive desktop et mobile.

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages
- Intelligence Artificielle Générative
- Figma / Figma Make
