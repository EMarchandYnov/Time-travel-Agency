# ⏳ TimeTravel Agency

Projet réalisé dans le cadre du module **Webapp Interactive** à **Ynov Toulouse**.

## 📖 Description

TimeTravel Agency est une application web interactive permettant aux utilisateurs de réserver et personnaliser un voyage temporel grâce à l'intelligence artificielle.

L'utilisateur peut explorer différentes époques, découvrir des destinations historiques immersives, interagir avec un agent conversationnel et obtenir une expérience de voyage personnalisée.

## 🎯 Objectifs du projet

* Concevoir une expérience utilisateur immersive.
* Développer une application web interactive.
* Intégrer des fonctionnalités basées sur l'intelligence artificielle.
* Utiliser GitHub comme outil de gestion et de suivi du projet.
* Mettre en œuvre un workflow collaboratif assisté par IA.
* Déployer une version fonctionnelle de l'application.

## 🚀 Fonctionnalités

* Landing page immersive.
* Galerie de destinations temporelles.
* Sélection d'une période historique.
* Formulaire de réservation de voyage temporel.
* Agent conversationnel IA.
* Génération d'une expérience personnalisée.
* Interface responsive desktop et mobile.
